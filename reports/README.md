# Reports index

Every tracked file under `reports/` with its role. Historical reports are
never edited except by appending clearly dated correction notes;
`model-experiments.md` is append-only.

Naming convention (forward-only; existing files keep their names): new reports
use kebab-case, and dated research notes or machine evidence files carry a
`-YYYYMMDD` suffix. Nothing in this index moves or renames an existing file.
